# 探索・案内 機能仕様書（箕面倒木報告）

**状態:** 実装済み（2026-11-27。アプリの版 `app-shell-2026-11-27.7`）
**最終更新日:** 2026年11月27日

---

## 1. 概要

### 1.1 目的

撮った写真の撮影地点（倒木のある場所など）を、ハイキングマップの上で探し、現在地からその地点までの方角と距離を示して案内する。

### 1.2 入口

起動時画面の「探索・案内」ボタン（`#ftBtnGuide`）。押すと、ほかのボタンと同じく更新版を確かめてから、ハイキングマップ画面を開き、写真の一覧を出す。

### 1.3 決定事項（2026-11-27）

| 事項 | 決定 |
|---|---|
| 画面 | ハイキングマップ画面に、写真の一覧・番号の印・矢印・方角と距離を重ねて出す |
| 番号 | 撮影順に ①、②、…、⑳、21 枚目からは (21)、(22)、… とする。撮影日時が無い写真は、その後に現在地から近い順に付ける。写真の増減などで番号がずれてもよい |
| カメラの印 | 探索・案内の間は、一覧に載っている写真のカメラの印を隠し、番号の印だけを出す |
| 途中で増減した写真 | 増えた写真は一覧に足さない。消えた写真は一覧から外す（ほかの番号は変えない） |
| 方角 | 8 方位（北・北東・東・南東・南・南西・西・北西）。地図と同じく北を基準にし、端末の向き（コンパス）は使わない |
| 距離 | 直線距離。「直線で約 120m」のように、直線だと分かる書き方にする。道に沿った案内はしない |
| 「現在地点をマーカー表示」がオフのとき | 現在地を続けて取れないので、オンにするよう知らせ、方角と距離の表示をやめる。アプリが自動でオンにはしない。後でオンになったら表示を再開する |
| 近くに着いたとき | 約 30m 以内に入ったら「近くに着きました」と知らせる |
| 閉じる（×） | 一覧・番号の印・矢印・方角と距離をすべて消し、ふだんのハイキングマップに戻る |

---

## 2. 操作の流れ

```
起動時画面「探索・案内」
  └─ ハイキングマップ画面 + 写真の一覧（広げた状態）
        │  写真を押す（一覧の行、または地図の番号の印）
        ▼
     案内: 矢印と方角・距離を出し、一覧はたたんでバーにする
        │  バーを押すと一覧を広げる（案内は続く。別の写真を押すと、その写真の案内に切り替わる）
        ▼
     × で閉じる ──> ふだんのハイキングマップ画面
```

- 写真が 1 枚も無いときは、画面を開かずに知らせる:
  「写真がありません。地図画面の「写真を撮影」で写真を撮るか、KMZ を読み込んでください。」
- 「≡」のメニューの「起動時の画面に戻る」で地図画面を離れたときも、探索・案内を終える（× と同じ）。
- 次に「探索・案内」を押すと、一覧を広げた状態から始める（前の案内の相手は覚えていない）。

## 3. 画面の構成

```
┌──────────────────────────┐
│                 [時刻][📷][▶][≡] │ ← 今の上部のボタン（変えない）
│ ┌ 探索・案内 ───── × ┐          │
│ │ ① 倒木A      [縮小] │          │ ← 写真の一覧（左上）
│ │ ② 倒木B      [縮小] │          │
│ │ ③ 倒木C      [縮小] │  ③        │ ← 番号の印
│ │  …（スクロール）    │   ↗       │
│ └─────────────┘  ↗        │ ← 矢印
│                    ●              │ ← 現在地
│ ┌──────────┐      [＋][－] │
│ │ ③ 倒木C          │      [◎]  │ ← 右下のボタン（変えない）
│ │ 北東　直線で約 120m│      縮尺  │
│ └──────────┘      出典  │ ← 方角と距離（左下）
└──────────────────────────┘
```

| 部品 | 位置と大きさ |
|---|---|
| 写真の一覧 | 左上。上部のボタンの列のすぐ下から始める（列と重ならない）。幅は画面の 6 割ほど（広い画面では上限を設ける）。高さは画面の半分まで。それより長いときは一覧の中をスクロールする |
| たたんだ一覧（バー） | 一覧と同じ左上。幅は文字に合わせる（一覧の幅まで） |
| 方角と距離 | 左下。下端は、画面の最下段の出典（国土地理院）より上。幅は画面の 6 割ほどまで。右下のボタン・縮尺・出典を隠さない。狭い画面（幅 320px）でも方角と距離が 1 行に収まるよう、文字を少し小さくする |

- 「≡」のメニューを開いたときは、メニューを一覧より上に出す。
- 地図の表示範囲は、探索・案内のために動かさない（「現在地点は中央に表示」がオンなら、ふだんどおり現在地に寄る）。

## 4. 写真の一覧

### 4.1 対象と番号

| 項目 | 仕様 |
|---|---|
| 対象 | アプリの中の写真全部（地図画面の「写真を撮影」で撮ったものと、KMZ で読み込んだもの）。`photos.js` の `getPhotos()`。写真には必ず撮影地点がある |
| 番号の順 | 1. 撮影日時がある写真を、撮影日時の古い順に<br>2. その後に、撮影日時が無い写真（ほかのアプリの KMZ から読んだものなど）を、現在地から近い順に |
| 番号の書き方 | ①〜⑳、21 からは (21)、(22)、…（報告書の写真の番号と同じ書き方。`ft-report-data.js` の `circledNumber`） |
| 撮影日時が無い写真の並べ方 | 一覧を作るときに分かっている現在地から近い順。現在地がまだ分からないとき（測位の前、「現在地点をマーカー表示」がオフのときなど）は、写真の一覧と同じ順（読み込んだ順）で仮に付け、その後に初めて現在地が分かったときに一度だけ並べ直す。歩いても並べ直さない |
| 番号のずれ | 探索・案内を始めるたびに番号を付け直すので、前回と番号が変わることがある（それでよい）。報告書の写真の番号（選んだ順）とは関係がない |

### 4.2 表示

- 見出し「探索・案内」と、右上に閉じるボタン（×）。
- 1 行に 1 枚。左に番号と名前（長い名前は 1 行に収めて「…」で切る）、右に縮小画像（`getPhotoThumbUrl()`）。
- 案内している写真の行は、色を変えて分かるようにする。
- 写真は最大 200 枚（`PHOTO_MAX_COUNT`）入るので、縮小画像は、一覧で見える位置に来た行から順に読み込む。

### 4.3 写真を押したとき

- その写真の案内を始める（→ [6](#6-案内)）。案内中に別の写真を押すと、その写真の案内に切り替える。
- 一覧をたたみ、左上にバーとして出す。バーには案内している写真の番号と名前を出す（例「③ 倒木C ▼」）。
- バーを押すと、一覧を広げる（案内は続ける）。広げた一覧で、案内中の写真をもう一度押すと、案内を続けたままたたむ。

### 4.4 閉じる（×）

- 探索・案内を終える。一覧（バー）・番号の印・矢印・方角と距離をすべて消し、隠していたカメラの印を戻す。
- 地図画面はそのまま（ふだんのハイキングマップ画面になる）。

---

## 5. 番号の印

- 写真の撮影地点に、一覧と同じ番号の印を置く。オレンジの丸に白い数字（報告書の地図の写真の印と同じ色 `#ea580c`）。丸が印の役をするので、数字は「3」「21」のように丸囲みや括弧を付けずに書く。
- 案内している写真の印は、大きくして縁取りを付け、ほかの印より上に出す。
- 印を押すと、一覧でその写真を押したときと同じにする（→ [4.3](#43-写真を押したとき)）。
- 探索・案内の間は、一覧に載っている写真の撮影地点のカメラの印（minoh-hiking の印。押すと写真が開く）を隠す。一覧に載っていない写真（探索・案内の途中で撮った写真など。→ [6.5](#65-探索案内の間に写真が増減したとき)）は、カメラの印のまま出す。ハイキングマップの緊急ポイント・ルートなどの表示は変えない。

## 6. 案内

### 6.1 矢印

- 現在地から写真の撮影地点まで、直線の矢印を引く（オレンジの線に白い縁。撮影地点の側に矢じり）。
- 撮影地点が画面の外にあっても線を引く。線は画面の端まで伸び、その方向を示す。地図を動かして現在地が画面の外に出たときも同じ。
- 矢じりの位置:
  - 撮影地点まで見えているときは、矢じりの先を撮影地点の少し手前（18px）に置く（番号の印に隠れないように）。
  - 撮影地点が画面の外にあるときは、矢じりの先を画面の端に合わせる。
  - 見えている線が矢じりより短いときは、矢じりを付けない。
- 現在地が変わるたびに引き直す。地図を動かしている間は、画面の端の位置が動かし終えるまで前のままになる（指を離すと合う）。

### 6.2 方角と距離

左下に、次の 2 行を出す。現在地が変わるたびに出し直す。

```
③ 倒木C
北東　直線で約 120m
```

| 項目 | 仕様 |
|---|---|
| 方角 | 現在地から見た撮影地点の向きを 8 方位で出す（場所の参考と同じ計算。`ft-report-data.js` の `bearingDegrees`・`directionName8`）。約 0m のときは、向きが決まらないので出さない |
| 距離 | 直線距離。100m 未満は 1m 単位、1km 未満は 10m 単位、1km 以上は 0.1km 単位（「直線で約 1.2km」） |

### 6.3 現在地が分からないとき

| 状況 | 方角と距離の場所に出すもの | 矢印 |
|---|---|---|
| 「現在地点をマーカー表示」がオフ | 「「現在地点をマーカー表示」がオフのため、現在地を続けて取得できません。≡ のメニューでオンにすると、方角と距離を表示します。」 | 出さない |
| オンで、まだ位置が取れていない | 「現在地を調べています…」 | 出さない |
| 位置が取れない（位置情報の利用が許可されていない・端末が対応していない） | 「現在地が分かりません。」 | 出さない |

- 「現在地点をマーカー表示」は、アプリが自動でオンにはしない（利用者が「≡」のメニューでオンにする）。
- 案内の途中でオフにしたら、矢印と方角・距離を消して、上の知らせに替える。後でオンにしたら、現在地が分かりしだい、矢印と方角・距離の表示を再開する。
- 「現在地点は中央に表示」は関係しない（オフでも、「現在地点をマーカー表示」がオンなら案内できる）。

### 6.4 近くに着いたとき

- 撮影地点まで約 30m 以内に入ったら、「近くに着きました（③ 倒木C）」と知らせる（画面下のトースト）。
- 知らせるのは、その写真の案内 1 回につき 1 度だけ。別の写真を選ぶか、同じ写真を選び直したら、また知らせる。写真を押した時点で 30m 以内なら、すぐに知らせる。
- 知らせた後も、矢印と方角・距離は出し続ける。
- GPS の位置には数 m〜十数 m の誤差があるため、30m は目安。

### 6.5 探索・案内の間に写真が増減したとき

一覧に載せる写真は、探索・案内を始めたときに決める（2026-11-27 利用者の決定）。

| 場合 | 仕様 |
|---|---|
| 写真が増えた（地図画面のカメラのボタンで撮った、KMZ を読み込んだ） | 一覧にも番号の印にも足さない。増えた写真は、ふだんどおりカメラの印で地図に出す |
| 写真が消えた | その写真の行を一覧から外し、番号の印も消す。ほかの写真の番号は変えない（欠番になる） |
| 案内している写真が消えた | 上に加えて、案内をやめ（矢印と方角・距離を消す）、一覧を広げる |
| 一覧の写真が全部消えた | 一覧に「写真がありません」と出す（× で閉じられる） |

---

## 7. 保存するもの・しないもの

- 何も保存しない。案内の相手（どの写真に向かっていたか）も覚えない。アプリを開き直すと、探索・案内は終わっている。
- 写真の名前・位置・画像は変えない。消さない。
- 現在地はサーバーに送らない（端末の中で地図の表示と方角・距離の計算に使うだけ）。

## 8. 実装の構成

| ファイル | 役割 |
|---|---|
| `public/js/ft/ft-explore.js`（新規） | 探索・案内の全部（一覧・番号の印・矢印・方角と距離・近くに着いた知らせ・現在地の監視） |
| `public/js/ft/ft-main.js` | 「探索・案内」ボタンから `ft-explore.js` を開く（更新版の確認は、地図画面へ切り替えるボタンが行うので、ここでは呼ばない） |
| `public/css/ft-style.css` | 一覧・バー・番号の印・方角と距離の見た目。探索・案内の間にカメラの印を隠す指定 |
| `public/service-worker.js` | `SHELL_LOCAL_PATHS` の ft-report 専用の区画に `ft-explore.js` を足す。版名を上げる |

- minoh-hiking 由来のファイル（`geolocation.js`・`photos.js`・`index.html` など）は変えない。
  - 地図画面へは、起動時画面の「ハイキングマップ表示」のボタンを押す形で切り替える（あわせて更新版も確認される）。地図画面を離れたことは、`#viewMap` が隠れたことで知る。
  - 現在地は、探索・案内の間で、「現在地点をマーカー表示」がオンのときだけ、`ft-explore.js` が自分で監視する（`navigator.geolocation.watchPosition`）。オン・オフは `#toggleCurrentMarker` の変化で知る。
    - 直近 30 秒以内の位置なら、監視を始めてすぐに使う（オンに戻したとき、立ち止まっていても方角と距離がすぐ出るように）。
  - 写真が消えたことは、一覧の写真のカメラの印（`photo-marker`）が地図から外されるのを見て知る（増えたことは知らなくてよい）。
  - カメラの印は、一覧に載っている写真の印にだけ class を付け、`ft-style.css` で隠す（「マーカーの設定」で印が作り直されたときも隠し直す）。
  - 矢印は、地図の線（ルートなど）より上、マーカーより下の専用の重なりに、SVG で描く。矢じりは SVG の marker で付ける。
- 画面の文言は日本語だけ（英語を選んでも日本語のまま）。

---

## 9. 今回はしないこと

- 端末の向き（コンパス）に合わせた方角（「右前方」など）。
- 道（ハイキングルート）に沿った道順・距離の案内。
- 音声や振動での案内。
- 案内中に画面を消さない（スリープさせない）こと。
