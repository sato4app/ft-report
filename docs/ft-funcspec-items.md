# 項目設定 機能仕様書（箕面倒木報告）

**状態:** 実装済み（2026-11-26。アプリの版 `app-shell-2026-11-26.6`）
**最終更新日:** 2026年11月26日

---

## 1. 概要

### 1.1 目的

発見報告・処理報告の入力の画面で、どの項目を入力するか、最初から入る値（初期値）、入力欄で選べる候補を、利用者が決められるようにする。

### 1.2 入口

起動時画面の「項目設定」ボタン（`#ftBtnItems`）。「処理報告」の下に置く（処理報告の下端は画面の上から 4 割のまま）。

### 1.3 決定事項（2026-11-26）

| 事項 | 決定 |
|---|---|
| 決められること | 項目ごとに、入力する・しない、初期値、候補 |
| 設定の単位 | 報告の種類（発見報告・処理報告）ごとに分ける |
| 処理報告 | まだ作っていない。設定は先に決められ、処理報告を作ったときに使う |
| 様式に無い項目を足すこと | しない（報告書の様式の欄は変えない） |
| 発見報告の「前回の値を覚える」 | やめる。代わりに項目設定の初期値を使う（→ [4](#4-前回の値を覚えていた版からの引き継ぎ)） |

---

## 2. 画面

```
┌ 項目設定 ─────────────── × ┐
│ [発見報告] [処理報告]        │ ← 報告の種類の切り替え
│ 説明                          │
│ ┌──────────────────────┐ │
│ │☑ 日時            入力する │ │ ← 項目ごとの枠
│ │  写真の撮影日時から作ります│ │
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │☑ 記入者          入力する │ │
│ │  初期値 [          ]     │ │
│ │  候補（1 行に 1 つ）     │ │
│ │  [                  ]     │ │
│ └──────────────────────┘ │
│   …                          │
│ [保存] [キャンセル]           │
│ [この報告の設定を初めの状態に戻す] │
└──────────────────────────┘
```

- 項目は様式の欄の順に並べる。
- 「入力する」を外した項目は、項目名を薄くし、初期値・候補の欄を閉じる（値は残る）。
- 報告の種類を切り替えても、保存するまでの変更は両方とも残る。
- 「処理報告」を選んでいるときは、「処理報告はまだ作っていません。ここでの設定は、処理報告を作ったときに使います。」と出す。
- 「保存」で両方の報告の設定を保存して閉じ、「項目の設定を保存しました」と知らせる。
- 「キャンセル」「×」は保存せずに閉じる。画面の外側（背景）を押しても閉じない（変更をうっかり失わないため）。
- 「この報告の設定を初めの状態に戻す」は、確認のあと、選んでいる報告の種類の設定を初めの状態にする（「保存」を押すまでは保存されない）。

## 3. 項目と、決められること

| 項目 | 入力する・しない | 初期値 | 候補 | 初めの状態 |
|---|---|---|---|---|
| 日時 | ○ | — （写真の撮影日時から作る） | — | 入力する |
| 天気 | ○ | 文字 | ○ | 候補: 晴・曇・雨・雪 |
| 気温（℃） | ○ | 数字 | — | 初期値なし |
| 記入者 | ○ | 文字 | ○ | 初期値なし |
| 対象案件 | ○ | 文字 | ○ | 初期値なし |
| 場所 | ○ | 文字 | ○ | 初期値なし |
| 通報先 | ○ | 文字 | ○ | 初期値なし |
| 通報手段 | ○ | 文字 | ○ | 候補: メール・電話・LINE |
| 通報日時 | ○ | — （今日の日付） | — | 入力する |
| 参加者 | ○ | 文字 | ○ | 初期値なし |
| 活動内容 | ○ | 文字（複数行） | — | 初期値なし |
| 写真の見出し | ○ | — （写真の名前） | — | 入力する |
| 通報先へ連絡 | ○ | 要・不要・未選択 | — | 未選択 |
| 行政への連絡 | ○ | 要・不要・未選択 | — | 未選択 |
| 連絡事項 | ○ | 文字（複数行） | — | 初期値なし |

- 番号は入力しない（空欄で出す）ので、項目設定には無い。
- 初めの状態では、全部の項目を入力する。
- 候補は 1 行に 1 つ書く。空の行は無視する。候補が無い項目は、入力欄に候補を出さない。

### 3.1 入力の画面での使われ方（発見報告）

- 「入力する」を外した項目は、入力の画面に出さない。報告書では、その欄を空欄にする（様式の欄そのものは残す）。
  - 日時を外すと、写真の撮影日時から作らない。写真の見出しを外すと、報告書の見出しは「①」だけになる。場所を外すと、場所の参考（近い緊急ポイント）も出さない。
  - 2 つ並んだ欄（天気と気温、通報手段と通報日時）が両方とも外れたら、行ごと出さない。
  - 全部の項目を外すと、「項目設定で、入力する項目がすべて外されています。」と出す。
- 初期値は、入力の画面を開いたときに欄に入れる。書き換えてよい。
- 候補は、入力欄で選べるようにする（文字の入力欄の候補一覧。候補に無い値も書ける）。

## 4. 前回の値を覚えていた版からの引き継ぎ

- 以前の版の発見報告は、記入者・通報先・通報手段を localStorage の `ft-report.found.lastInputs` に覚え、次の初期値にしていた。この版から覚えない。
- 項目設定をまだ一度も保存していない端末では、発見報告の記入者・通報先・通報手段の初期値として、`ft-report.found.lastInputs` の値を使う（項目設定の画面にもその値が出る）。保存すると、以後は項目設定の値を使う。

---

## 5. 保存

- 設定は端末の localStorage のキー `ft-report.itemSettings`（JSON）に保存する。サーバーには送らない。
  - 形: `{ "found": { "<項目>": { "enabled": true, "default": "", "candidates": [] }, … }, "process": { … } }`
  - 項目の名前（`<項目>`）は `public/js/ft/ft-report-items.js` の `REPORT_ITEMS` の `key`（`date`・`weather`・`temperature`・`writer`・`subject`・`place`・`reportTo`・`reportMeans`・`reportDate`・`participants`・`body`・`captions`・`contactReportTo`・`contactGov`・`notes`）。
- 読むときは、今の項目の一覧に合わせて整える（後で項目が増えても減っても読める。足りない項目は初めの状態）。

## 6. 実装の構成

| ファイル | 役割 |
|---|---|
| `public/js/ft/ft-report-items.js` | 記入項目の一覧（`REPORT_ITEMS`）と、報告の種類ごとの設定の読み書き（`loadItemSettings`・`saveItemSettings`）。発見報告・処理報告で共通 |
| `public/js/ft/ft-item-settings.js` | 項目設定の画面。開くたびに作り、閉じたら取り除く |
| `public/js/ft/ft-found.js` | 発見報告の入力の画面に、設定を当てはめる（`applySettings`）。入力しない項目は空にして報告書に渡す |
| `public/js/ft/ft-main.js` | 起動時画面の「項目設定」ボタン |
| `public/css/ft-style.css` | 項目設定の画面と、ボタンの位置（`.ft-home-btn-below`） |
